# ishita-bery-portfolio

Personal portfolio website for **Ishita Bery** — AI/ML Engineer specializing in computer vision, deep learning pipelines, and edge-deployed intelligent systems.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Fonts**: JetBrains Mono · Space Grotesk · DM Sans

## Design

Dark, neural-network-inspired aesthetic — electric cyan/violet palette with a grid background, noise texture overlay, and scroll-triggered reveal animations. Built for recruiter impact: key information visible within 5 seconds of landing.

## Sections

- **Hero** — Typewriter role animation, stats, network SVG backdrop
- **About** — Terminal-style personal details + competency bars
- **Projects** — 4 featured ML and full-stack projects with impact bullets
- **Experience** — Timeline layout for research intern + leadership roles
- **Skills** — Grouped technical skill chips (6 categories)
- **Achievements** — Google Big Code, Dronolympics finalist, academic record
- **Contact** — Email CTA + LinkedIn / GitHub / Phone links

## Local Setup

```bash
# 1. Clone or unzip the project
git clone https://github.com/ishitabery/ishita-bery-portfolio.git
cd ishita-bery-portfolio

# 2. Install dependencies
npm install

# 3. Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm run start
```

No environment variables required.
